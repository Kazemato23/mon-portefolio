Projet 1: Motus

Description : Motus est un jeu Dans lequelle il faut trouver un mot qui est choisi aux hasard , généralement à l'aide de 6 essaie vous devez entrée un mot "valide" c'est-à-dire un mot qui existe et qui est reconnu.Les lettres du mot s'afficherons soit en grisée si la lettre n'est pas présent dans le mot à trouver , en jaune si elle est présente mais mal placée et en verte si elle est bien placée.Vous gagné si vous trouver le mot avant que votre nombre d'essai soit de 0 . Dans le cadre d'un devoir dans le module info 1 , nous avons coder en python le jeu Motus.

Objectif : Être capable de coder en python le célebre jeu Motus

Projet 3: Echec

Projet 4: Liste de noël

Description : Une page dans laquelle se trouve ma liste de souhait pour noël , dans lequelle on retrouve juste des images des choses que je veux pour noël , de tel sortes à ce que quand on click sur l'image on est renvoyer vers une page qui contient plus d'information . Ce site est intéressant car il permet de plus facilement et rapidement avoir les informations sur les cadeaux souhaiter.

Objectif : Apprendre à placer des images , les utiliser mais aussi apprendre à utiliser les liens de sorte à ce que quand on click sur l'image on est renvoyer vers le site choisi , notament celui de l'achat dans le cas de ce site. Ce site a aussi permet de travailler et revoir les méthodes pour faire un site résponsif
